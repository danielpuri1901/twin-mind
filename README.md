# Super Project

Home for **Twin Mind**: a personal AI that drafts in your voice, acts across your tools, and coaches you toward your best self. You stay in the loop on everything.

- **Design + build plan:** [docs/2026-06-30-twin-mind-design.md](docs/2026-06-30-twin-mind-design.md)
- **Stack:** Hermes Agent on a small AWS box, Claude via Bedrock, Langfuse Cloud for traces + the scorecard, your data in a git folder.
- **Rule:** measure before you build. Nothing ships unless it beats the scorecard.
- **Status:** scope locked. Building Phase 0.
