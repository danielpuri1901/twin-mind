Twin Mind - Agent Eval, AWS-aligned

The Twin Mind version of the AWS Strands eval blueprint. Same practice, same 10 evaluators, adapted to what the Twin is: a personal capture, recall, and reflection agent on Telegram, grounded in your corpus. Adopt the practice, not the library (Strands ≠ Hermes) · binary scoring, not scales · offline over your history, because usage is sporadic. Full write-up: docs/evaluating-twin-mind-agent.md.

4 · The offline Task Function (the fit for sporadic use)

def twin_task(case):
    trace = load_trace_from_state_db(case.session_id)
    return {
      "input": case.input,
      "final_response": assistant_reply(trace),
      "trajectory": tool_calls(trace),      # corpus-search, notion...
      "retrieved_context": corpus_hits(trace),  # source for faithfulness
    }

Evaluate your recorded history, not a live sample. Same evaluators + same gate whether the case came from state.db or a live CI run - only the Task Function changes. This is the AWS offline_task pattern, and it's why low volume stops being a problem.

Intents: capture · recall · reflect. Row = {input, expected_output, expected_trajectory, metadata}. Start ~30-50/intent from your 114 turns; grow weekly.

6 · Metrics + the gate

pass^k (all k trials succeed, n≥3) · trajectory match subset/superset, never strict · gate per-dimension vs baseline, never on an aggregate - a strong helpfulness can't hide a weak faithfulness. A prompt / skill / tool-schema edit trips the gate (no code-vs-config line for agents). Three layers, all must pass: tool-use (code) > 95% · reasoning/faithfulness (judge) > 85% · output quality (judge) > 90%.

7 · The build

  1. Clean + plugin v2. Remove the sprawl (§8); add trajectory + tokens + turn-success.
  2. Cases from your history. Mine 114 turns → Case rows by intent (capture/recall/reflect); label ~30-50 in the UI.
  3. Wire it. Offline Task Function over state.db + the 10 evaluators into align.py; run the first gate.
  4. Monitors + thumbs. compression_ok + safe_output on 100%; wire the 👎 signal.
  5. Grow. Golden set grows from thumbs + flagged; add the sampled judge only once volume rises.
