Twin Mind - Corpus Ingestion

Daily cron. Read new Claude Code transcripts, scrub secrets on the Mac, embed with Cohere on Bedrock, and append to the same growing vector store as everything else. It accumulates - never a daily rebuild.

One new source normalizer (normalize_claude_code.py) + reuse the existing incremental embed path. Every session you have with Claude Code compounds into the same store the Twin already reads - the flywheel, made literal.
